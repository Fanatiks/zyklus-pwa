# ZyklusTracker (PWA)

Eine moderne, schlanke Progressive Web App (PWA) für iOS und Android zum einfachen und privaten Verfolgen des Menstruationszyklus.

## Features
- **Kalender-Startseite**: Übersicht über den aktuellen Zyklus, Tage bis zur nächsten Periode und fruchtbare Phasen.
- **Start- & End-Buttons**: Mit einem Fingertipp Start (rotes Symbol) oder Ende der Menstruation festlegen.
- **Zyklus-Verlauf**: Diagramme und Historie der vergangenen Menstruationszyklen inkl. Durchschnittsberechnungen.
- **100% Privat**: Alle Daten bleiben lokal auf deinem Gerät im Browser-Speicher (`localStorage`).
- **Offline-fähig**: Funktioniert auch ohne Internetverbindung dank Service Worker.
- **Kein Signieren / Kein Ablauf**: Läuft dauerhaft auf dem Homescreen wie eine native App.

## Auf dem iPhone installieren
1. Öffne die Seite in **Safari**.
2. Tippe unten auf das **Teilen-Symbol** (Viereck mit Pfeil nach oben).
3. Wähle **„Zum Home-Bildschirm“** und tippe auf **Hinzufügen**.
